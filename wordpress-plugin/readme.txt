Saves approved AMPLIFY SEO titles, meta descriptions, featured-image metadata, and JSON-LD schema for WordPress pages and blog posts.

== Changelog ==

= 1.9.6 =
* Automatically lists published topical child pages on their Billy Cooper location parent page.
* Keeps the parent-page directory current when child pages are manually published or unpublished in WordPress.

= 1.9.5 =
* Starts the Billy Cooper hero safeguard for the site request, then scopes the replacement from the final AMPLIFY source marker in rendered markup.
* Targets the exact inner hero-image class without matching the surrounding grid wrapper.

= 1.9.4 =
* Guarantees the Billy Cooper theme hero renders the verified WordPress featured image on AMPLIFY pages, including draft previews.
* Restricts legacy source-marker detection to the Billy Cooper Law hostname.

= 1.9.3 =
* Detects legacy AMPLIFY Billy Cooper drafts by their source marker when client metadata is unavailable in preview context.

= 1.9.2 =
* Resolves WordPress preview and revision identifiers before applying the Billy Cooper hero-image safeguard.

= 1.9.1 =
* Normalizes the verified Billy Cooper hero attachment into the image-array shape required by the active theme.

= 1.9.0 =
* Ensures AMPLIFY Billy Cooper draft previews render the page's verified featured image whenever the ACF hero value is unavailable in the preview context.

= 1.8.0 =

= 1.7.0 =

= 1.6.0 =
